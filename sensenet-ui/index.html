SenseNet

Version 1.0.0 (Hackathon Build)

SenseNet is a real-time assistive alert system designed for individuals with hearing impairment. It listens for dangerous sounds using the phone's microphone, verifies danger, captures a visual frame, and sends a haptic alert to a wearable ESP32 wristband.

Features

  • Local AI Sound Classification (YAMNet)
  • Automated Visual Context Capture
  • ESP32 Hardware Integration
  • 100% On-Device Processing
