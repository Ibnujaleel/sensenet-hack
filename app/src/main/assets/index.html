    SenseNet

    Version 1.0.0 (Hackathon Build)

    SenseNet is a real-time assistive alert system designed for individuals with hearing impairment. It listens for dangerous sounds using the phone's microphone, verifies danger with visual AI, and sends a haptic alert to a wearable ESP32 wristband via BLE.

    Features

    • Local AI Sound Classification (YAMNet)
    • YOLOv8 Person Detection
    • ESP32 BLE Hardware Integration
    • Priority-Based Alerts (High / Low)
    • 100% On-Device Processing
